# CapFix fabrication review files

These exports belong only to the PCB in this CapFix folder. Do not combine them with earlier A3/A4 exports.

- Board: 100 x 80 mm; four copper layers; nominal thickness 1.6 mm. Confirm the actual fabricator stack-up before ordering.
- Backside SMD assembly: C14, C27, R21 and C23. All other components mount on top. Both paste layers and both assembly drawings are supplied.
- Use the supplied Excellon drill files and distinguish plated from non-plated holes. MCU sockets require soldered headers; empty holes are not plug-in contacts.
- Verify the purchased Waveshare Tiny/header fit against the dimensional template before fabrication. No physical fit test has been performed.
- Layout and electrical-rule checks pass; no physical noise, RLD-stability or safety test has been performed. This remains a bench/review prototype, not a validated body-connected product.

See ../README.md and ../PLACEMENT_RESULTS.md for assembly, safety and numerical verification details.
